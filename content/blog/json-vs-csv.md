# JSON 与 CSV 对比

CSV 是逗号分隔的表格格式，适合扁平结构化数据；JSON 适合嵌套与混合类型。

## 适用场景

CSV 适合导出 Excel、数据库表、扁平数据；JSON 适合 API、嵌套结构、配置。

## 互转注意

JSON 转 CSV 仅适合数组对象结构，嵌套数据需先扁平化。

## 代码示例

```json
id,name,age
1,张三,28
2,李四,30
```
