# JSON 转 Markdown 表格教程

将 JSON 对象数组转为 Markdown 表格，键作为表头，值作为单元格，便于文档展示。

## 转换规则

数组对象的键生成表头行，每个对象生成一行数据，用 | 分隔。

## 使用场景

生成 README 表格、文档数据展示、API 字段说明。

## 代码示例

```json
[{"name":"a","age":1},{"name":"b","age":2}]
```
