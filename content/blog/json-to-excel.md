# JSON 转 Excel 教程

将 JSON 数组导出为 Excel xlsx 文件，键作为列名，用于数据分析与报表分发。

## 转换条件

JSON 须为对象数组，每个对象的键作为列，值作为单元格。

## 使用场景

导出业务数据、生成报表、与 Excel 用户协作。

## 代码示例

```json
[{"id":1,"name":"a"},{"id":2,"name":"b"}]
```
