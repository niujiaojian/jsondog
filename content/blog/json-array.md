# JSON 数组详解

JSON 数组是有序的值列表，用方括号包裹，元素之间用逗号分隔，元素可以是任意 JSON 类型。

## 数组特性

数组保持元素顺序，通过索引访问，可包含混合类型元素，也可嵌套对象或数组。

## 使用场景

数组常用于表达列表、集合、分页数据、标签等有序数据。

## 代码示例

```json
[1, "two", true, null, {"five": 5}, [6, 7]]
```
