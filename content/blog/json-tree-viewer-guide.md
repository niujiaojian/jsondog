# JSON 树查看器使用指南

JSON 树查看器将 JSON 渲染为可折叠的树形结构，层级一目了然，特别适合查看大型嵌套 JSON。

## 核心功能

折叠展开节点、搜索键名高亮、点击复制 JSONPath 路径，快速定位数据。

## 适用场景

查看 API 返回、调试嵌套配置、分析复杂数据结构。

## 代码示例

```json
{"store": {"book": [{"title": "A", "price": 12}]}}
```
