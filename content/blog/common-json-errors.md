# 常见 JSON 错误及解决方法

使用 JSON 时会遇到多种高频错误，本文汇总原因与修复方法。

## 语法错误

单引号改双引号、删除尾逗号、补全引号与逗号、检查括号匹配。

## 解析错误

Unexpected token 多为非法字符，Unexpected end 多为括号未闭合。

## 代码示例

```json
{'key': 'value',}
```
