# JSON 语法详解与规则

JSON 语法非常简洁，但有几条必须严格遵守的规则，违反任何一条都会导致解析失败。

## 基本规则

键名与字符串必须用双引号包裹；键值对用冒号分隔；多个元素用逗号分隔；对象用花括号、数组用方括号；最后一个元素后不能有尾逗号。

## 常见错误

使用单引号、键名未加引号、多余逗号、缺少引号是最高频的 JSON 语法错误。

## 代码示例

```json
{"name": "张三", "age": 28, "hobbies": ["阅读", "编程"]}
```
