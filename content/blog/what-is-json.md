# 什么是 JSON？JSON 入门详解

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式，基于 JavaScript 语法的子集，采用完全独立于语言的文本格式。它易于人阅读编写，也易于机器解析生成，是当今 Web 开发中最常用的数据格式之一。

## JSON 的特点

JSON 采用键值对结构，支持字符串、数字、布尔、null、对象、数组六种数据类型，结构清晰、体积小、跨平台兼容性好。

## JSON 的用途

JSON 广泛用于 API 接口返回、配置文件、NoSQL 数据库存储、前后端数据交换等场景。

## 代码示例

```json
{
  "name": "JSONDog",
  "version": "0.1.0",
  "openSource": true
}
```
