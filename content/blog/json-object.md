# JSON 对象详解

JSON 对象是 JSON 最核心的结构，用花括号包裹的键值对集合，键名必须是双引号字符串。

## 对象结构

对象由零或多个键值对组成，键值对之间用逗号分隔，键与值用冒号连接。键名唯一，重复键后值覆盖前值。

## 嵌套对象

对象的值可以是另一个对象，形成多层嵌套，适合表达层级数据。

## 代码示例

```json
{"user": {"name": "李四", "address": {"city": "上海"}}}
```
