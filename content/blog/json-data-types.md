# JSON 数据类型全览

JSON 规范定义了六种数据类型，理解每种类型的特征是正确使用 JSON 的基础。

## 基本类型

string 字符串（双引号）、number 数字（整数或浮点）、boolean 布尔（true/false）、null 空值。

## 复合类型

object 对象（无序键值对集合）、array 数组（有序值列表），二者可无限嵌套。

## 代码示例

```json
{"str": "text", "num": 42, "bool": true, "nil": null, "obj": {}, "arr": []}
```
