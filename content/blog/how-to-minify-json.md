# 如何压缩 JSON：Minify

JSON 压缩（minify）去除所有不必要的空白、换行与缩进，将 JSON 压成单行，减小传输体积。

## 压缩好处

减小文件体积，加快网络传输，节省存储空间，适合生产环境。

## 开发建议

开发时用格式化便于阅读，部署时用压缩优化性能。

## 代码示例

```json
{"a":1,"b":[2,3],"c":{"d":4}}
```
