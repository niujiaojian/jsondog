# JSON Mock 数据生成

Mock 数据生成器根据 JSON 样本结构生成随机假数据，保持类型与层级，用于测试与开发。

## 生成规则

字符串生成随机串、数字生成随机数、布尔随机真假、null 保持、结构与嵌套保留。

## 使用场景

前端联调、单元测试、接口演示、占位数据。

## 代码示例

```json
{"id": 1, "name": "x", "active": true}
```
