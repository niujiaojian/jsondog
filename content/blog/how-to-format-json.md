# 如何格式化 JSON：美化与缩进

JSON 格式化又称美化（beautify）或 pretty print，指为压缩的 JSON 添加缩进与换行，使其结构清晰易读。

## 为什么格式化

压缩 JSON 单行难读，格式化后层级清晰，便于调试与排查错误。

## 如何操作

粘贴 JSON 到格式化工具，选择缩进（2/4 空格或 Tab），一键生成美化结果。

## 代码示例

```json
{"a":1,"b":{"c":2}}
```
