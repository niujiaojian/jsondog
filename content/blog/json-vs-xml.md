# JSON 与 XML 对比：该用哪个

JSON 与 XML 是两种主流数据交换格式，各有优劣，选择取决于场景。

## 主要差异

JSON 体积更小、解析更快、与 JavaScript 天然契合；XML 支持属性、命名空间、Schema 验证更完善。

## 选择建议

Web API、前后端交互首选 JSON；需要强结构验证、文档型数据可考虑 XML。

## 代码示例

```json
{"person": {"name": "张三", "age": 28}}
```
