## 3. 转换类工具页（双向，以 `/convert/yaml` 为例）

```
┌──────────────────────┬──────────────────────────────────────┐
│  JSON  [⇄]  YAML     │  方向切换                            │
├──────────────────────┼──────────────────────────────────────┤
│  ┌──────────────────┐│  ┌──────────────────────────────────┐│
│  │ JSON 输入         ││  │ YAML 输出                         ││
│  │                   ││  │                                   ││
│  └──────────────────┘│  └──────────────────────────────────┘│
│  [Sample▼]            │  [Copy][Download][⇄ Swap]           │
```

## 8. 全局组件清单

| 组件 | 说明 |
|------|------|
| `<ToolLayout>` | 双栏容器 + 状态栏 + 顶 Tab，所有工具页复用 |
| `<JsonInput>` | 输入区：上传/示例/清空/字符计数 |
| `<JsonOutput>` | 输出区：复制/下载/语法高亮 |
| `<StatusBar>` | 字符/行/节点/大小/耗时 |
| `<ErrorReport>` | 行/列/类型/修复建议 |
| `<RelatedTools>` | 底部内链 |
| `<FaqBlock>` | FAQ + FAQPage schema 注入 |
| `<CommandPalette>` | Ctrl+K 搜工具 |
| `<ThemeToggle>` | 暗浅切换 + localStorage |
| `<LangSwitch>` | 中英切换 + hreflang |
