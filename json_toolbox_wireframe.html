📐 布局说明

整体布局：顶部 Title Bar → Toolbar → 双栏 Split（左编辑器 / 右 Tree View）→ 底部 Status Bar。双栏比例默认 50:50，可拖拽调整。

编辑器：基于 Monaco Editor，支持语法高亮、错误波浪线、自动补全。行号区点击可选中整行。

Tree View：可折叠节点，悬停显示「Copy Path」按钮，点击复制 users.count 格式的路径。

状态栏：实时显示校验状态（绿/红/黄点）、行数、字节大小、解析耗时。这是开发者最关心的「一眼信息」。

RESPONSIVE DESIGN

六、响应式断点策略

适配桌面、平板、移动端的布局变化规则

≥ 1200px · DESKTOP
完整布局
  • 双栏 Split 50:50
  • 侧边栏 260px 常驻
  • Tree View 完整展开
  • 所有工具栏按钮可见
  • 命令面板居中弹窗
768–1199px · TABLET
紧凑布局
  • 双栏 Split 变为上下堆叠
  • 侧边栏折叠为汉堡菜单
  • 工具栏按钮折叠为「更多」
  • Diff 三栏变为单栏 Tab 切换
< 768px · MOBILE
极简布局
  • 仅保留编辑器 + Tree View Tab
  • 侧边栏全屏抽屉
  • 隐藏状态栏，改为 Toast
  • jq Playground 三栏变单栏
  • 提示「建议使用横屏模式」
